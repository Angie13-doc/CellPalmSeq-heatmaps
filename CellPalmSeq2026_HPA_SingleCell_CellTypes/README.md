# CellPalmSeq2026_HPA_SingleCell_CellTypes

HPA single-cell RNA expression. Source: `rna_single_cell_type.tsv` (user-provided HPA download).

40 genes matching the existing CellPalmSeq HPA normal-tissue matrix. Values are **nCPM** (not TPM or nTPM). Original metadata columns are preserved in the included filtered CSV and hover.

Upload this folder to the root of the `CellPalmSeq-heatmaps` GitHub repository.

Note: Source release version/date is not established from the TSV alone. No live browser testing performed.

# CellPalmSeq2026_Broad_CCLE

Uses the original BrainPalmSeq heatmap HTML/CSS/JS layout and controls, not a newly designed interface.

1406 cell lines, 40 genes. Full original source-matrix metadata in hover: Primary disease, Lineage, Cell line name, Cellosaurus id, Broad model id, RRID, Sanger Model ID, Source, Subtype, Primary or metastasis, CCLE name (short).

Original TPM preserved in hover and exported CSV; visualization colour is log₂(TPM + 1).

Upload this folder to the root of CellPalmSeq-heatmaps.
